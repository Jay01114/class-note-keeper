# 课堂笔记管家 (ClassNote Keeper)

> 手机录音 → 自动转写 → AI 纪要 → 按学科归档进 Obsidian 的**半自动化课堂笔记流水线**。
> 全部本地运行，永久免费，无需联网（除首次下载模型）。

---

## 为什么做这个（初衷）

作为一名学生，每天要上 4~8 节课，单节课录音经常超过 2 小时。课后的整理是最大的负担：

- 录音文件散落在手机里，从不回听；
- 想整理时，2 小时音频回放 + 手打笔记 = 一晚上就没了；
- 市面上没有"免费 + 本地 + 自动归档"的完整方案。

所以我们用**一堆开源小模块**（LocalSend + faster-whisper + Ollama/Qwen + Obsidian），把它们像流水线一样接起来，代替昂贵的商用产品。

## 工作流（架构一览）

```
┌─────────┐   LocalSend   ┌──────────────┐   自动检测    ┌──────────────────┐
│ 手机录音  │ ────────────▶ │  PC inbox 文件夹 │ ────────────▶ │ faster-whisper 转写 │
└─────────┘  （局域网直传）  └──────────────┘   （大小稳定）  └────────┬─────────┘
                                                                    │ 全文+时间戳
                                                                    ▼
┌──────────────┐   AI 纪要+学科识别    ┌──────────────────┐
│ Obsidian 知识库 │ ◀─────────────────── │ Ollama + Qwen2.5 │
│ 学科/纪要/转写  │    （本地模型）       └──────────────────┘
└──────────────┘
```

- **手机端**：系统自带录音机，录完用 LocalSend 发给电脑（唯一手动动作）
- **电脑端**：桌面应用监视 inbox 文件夹 → 新文件自动入队 → 转写 → AI 纪要 + 学科识别 → 归档进 Obsidian
- **知识库**：Obsidian 只做查看器，笔记文件按 `学科/{原材料,纪要,转写}/` 组织

## 特性

- ✅ 一次投递多条录音，自动排队处理（晚间批量整理）
- ✅ 半成品文件防护：文件大小稳定 6 秒才处理，传输一半不误触发
- ✅ 去重：同一录音不会重复转写
- ✅ 固定学科分类（可配置），未知内容进"待整理"
- ✅ 转写进度条、单实例、托盘继续监视
- ✅ 不常驻后台、不开机自启：打开才监视，关闭全停
- ✅ **2 小时以上长录音不丢内容**：分段独立整理 + 程序拼接成整门课纪要（不再截断）
- ✅ **术语纠错**：语音识别谐音误写（"容赤原理"→"容斥原理"等）按学科表自动纠正
- ✅ **知识补全**：纪要里原文含糊/缺失的知识点，经维基百科查证后以 `[补]` 标记内嵌补回
- ✅ 数学公式 LaTeX（`$...$` / `$$...$$`）写入，Obsidian 可直接渲染

## 快速开始（详见 docs/setup-guide.md）

```bash
# 1. 安装依赖（Python 3.11+）
pip install -r requirements.txt   # faster-whisper, ctranslate2, PySide6, requests, edge-tts, av, watchdog

# 2. 安装 Ollama 并拉取纪要模型
ollama pull qwen2.5:7b

# 3. 下载转写模型（faster-whisper，任选一档）
#    small / medium / large-v3，放到 models/ 目录（详见 setup-guide.md）

# 4. 配置
cp config.example.json config.json   # 按需修改路径与学科列表

# 5. 运行
python src/app.py
```

> 本仓库提供的是**工作流与代码**，不捆绑任何商业软件包；Ollama、模型等一律从官方渠道安装。

## 硬件与资源（实测：RTX 5060 8GB）

- 转写：medium 档，2 小时录音约 5~10 分钟，显存约 1.5~2.5GB
- 纪要：Qwen2.5-7B，单条约 1 分钟，显存约 4.7GB
- 串行执行，峰值显存约 5GB，8GB 显存安全
- 空闲不处理时：内存 < 200MB，GPU 0 占用
